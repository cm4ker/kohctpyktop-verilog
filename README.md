# КОНСТРУКТОР + Verilog

Неофициальный браузерный порт игры Zachtronics и TypeScript-синтезатор.

Оригинал: https://www.zachtronics.com/kohctpyktop-engineer-of-the-people/

`npm ci`, `npm run dev`, `npm test`, `npm run build`. Node.js 24+.

Игровой код — game/, синтезатор — synth/, исходные ресурсы — public/assets/. dist/ генерируется сборкой и не хранится в Git.

Оригинальная игра и ресурсы принадлежат Zachtronics; авторские права сохраняются.
