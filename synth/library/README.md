# Пользовательская библиотека Verilog

Добавляйте сюда `.v`-файлы (можно во вложенные папки). Интерфейс автоматически загружает все определения модулей при запуске и обновляет их через Vite при изменениях. Для готовой сборки после добавления файлов выполните `npm run build`.

Вызывайте модуль по его имени из редактора; копировать его определение в `root` не нужно. В библиотечных файлах не объявляйте `root`. Имена модулей должны быть уникальны между редактором и библиотекой. Ошибки в библиотеке показывают имя файла и строку.

Пример: `positive_edge_detector.v` вызывается так:

```verilog
module root(input pin1, output pin8);
    positive_edge_detector edge1(.in(pin1), .out(pin8));
endmodule
```

Явные примитивы: `transistor_n` и `transistor_p`. Порты `s` — вход канала, `g` — затвор, `d` — выход канала. На `s` и `g` допустимы скалярные сигналы и однобитные константы. `1'b1` подключается к VCC; `1'b0` — постоянный низкий уровень. `d` подключается к скалярному wire или выходному порту. Выходы нескольких транзисторов можно объединять; допускается обратная связь. Явно описанные транзисторы сохраняются.

N открыт при высоком уровне затвора, P — при низком. Состояние затвора обновляется раз в такт, а сигнал на входе канала проходит через открытый транзистор в текущем такте. Поэтому явный транзистор и логическое выражение могут отличаться задержками.

Можно записать несколько экземпляров одного типа через запятую, как в `positive_edge_detector.v`. Параметры пользовательских модулей пока не поддерживаются.
