# Системная Verilog-библиотека

Файлы por.v, delay_line.v, rs_trigger.v и positive_edge_detector.v описывают схемы через transistor_n/p. В интерфейсе они выключены по умолчанию; включите нужные флажки. Для por также нужен delay_line.

Системный код открыт только для чтения. «Скопировать» у имени файла создаёт пользовательскую копию. Перед её включением отключите оригинал или измените имя модуля в коде. Свои модули добавляйте кнопкой «+»: они сохраняются в localStorage и поддерживают экспорт/импорт JSON.

Примитивы transistor_n/p встроены в компилятор и всегда доступны, их порты — s, g, d. Все остальные модули разворачиваются из Verilog и разводятся общим роутером, без фиксированных макроячеек.
