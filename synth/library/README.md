# Библиотека модулей

Файлы .v этой папки доступны как системные модули в интерфейсе. По умолчанию они выключены и показаны серым; включите нужные флажки. Для por включите также delay_line.

Свои модули создавайте в панели библиотеки: они сохраняются в localStorage и доступны для редактирования, включения, экспорта и импорта. Чтобы изменить системный модуль, создайте его пользовательскую копию и отключите оригинал.

Добавление новых файлов в эту папку требует сборки для публикации; dev-сервер подхватывает изменения. Все имена модулей должны быть уникальны. Главный root хранится в редакторе, а не в библиотеке.

Примитивы transistor_n и transistor_p имеют порты s, g, d. На s/g разрешены скаляры и константы 1'b0/1'b1. Выходы d можно объединять. Явные транзисторы сохраняются, логические выражения оптимизируются.

Для повторяемых цепочек поддерживаются параметры 1–64, +/− в параметрах экземпляра и generate if/else с проверкой равенства. См. delay_line.v и por.v.
